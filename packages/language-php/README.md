# PHP language support in Pulsar

Adds syntax highlighting and snippets to PHP files in Pulsar.

Originally [converted](https://docs.pulsar-edit.dev/core-hacking/#converting-from-textmate) from the [PHP TextMate bundle](https://github.com/textmate/php.tmbundle).

Contributions are greatly appreciated. Please fork this repository and open a pull request to add snippets, make grammar tweaks, etc.
