# XML language support in Pulsar

Adds syntax highlighting and snippets to XML files in Pulsar.

Originally [converted](https://docs.pulsar-edit.dev/core-hacking/#converting-from-textmate) from the [XML TextMate bundle](https://github.com/textmate/xml.tmbundle).

Contributions are greatly appreciated. Please fork this repository and open a pull request to add snippets, make grammar tweaks, etc.
