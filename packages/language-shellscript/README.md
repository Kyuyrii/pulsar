# ShellScript language support in Pulsar

Adds syntax highlighting and snippets to shell scripts in Pulsar.

Originally [converted](https://docs.pulsar-edit.dev/core-hacking/#converting-from-textmate) from the [ShellScript TextMate bundle](https://github.com/textmate/shellscript.tmbundle).

Contributions are greatly appreciated. Please fork this repository and open a pull request to add snippets, make grammar tweaks, etc.
